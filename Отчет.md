## 📝 Описание программы

**«Умная База Тканей» (Fabric Database CRM)** — это специализированная система управления данными и ценами на ткани от различных европейских производителей и поставщиков. Система решает проблему ручного отслеживания цен и спецификаций тканей, предоставляя удобный веб-интерфейс для поиска и фильтрации.

### Ключевой функционал:
1. **Сбор данных (Парсинг/Импорт):**
   - Программа содержит автоматические скрипты для сбора информации с сайтов ключевых производителей (Davis, Litena, Toptextil) и из прайс-листов PDF/Excel (Dedar, Mariaflora).
   - Собираются все важные параметры: тест Мартиндейла (износостойкость), плотность (г/м²), категория ткани, её свойства (водоотталкивание, антикоготь, легкая чистка, переработанный полиэстер) и ссылки на официальные страницы продуктов.
2. **База данных:**
   - Хранение всех характеристик тканей и их цветовых палитр реализовано на базе реляционной СУБД SQLite (`fabrics.db`).
   - Каждая ткань может иметь неограниченное количество цветов с изображениями-образцами.
3. **Удобный поиск и фильтрация:**
   - Мгновенный текстовый поиск по названию ткани или производителю.
   - Фильтрация по брендам, категориям, типу ткани, специальным свойствам и минимальному количеству циклов Мартиндейла.
4. **Редактирование цен в реальном времени:**
   - Администратор может редактировать цену любой ткани прямо в карточке на интерфейсе (двойным кликом / фокусом на поле цены). Изменения мгновенно отправляются по API на сервер и сохраняются в базе данных.
5. **Галерея цветов:**
   - Интегрированное модальное окно для просмотра всех доступных цветов конкретной коллекции тканей с фотографиями образцов.

### Технологический стек:
- **Бэкенд:** Python, FastAPI, SQLAlchemy, Uvicorn, SQLite.
- **Фронтенд:** HTML5, CSS3 (адаптивная сетка CSS Grid/Flexbox), чистый JavaScript (Vanilla JS) для работы с API.
- **Парсеры:** Playwright (для динамических сайтов), openpyxl (Excel), PyPDF2 (PDF).

## 🛠 История изменений в программе

### 1. Архитектура базы данных и миграции
- Разработана схема БД с таблицами `fabrics` (характеристики ткани) и `fabric_colors` (цвета, пути к изображениям).
- Написаны и применены скрипты миграций (`migrate_v2.py`, `migrate_v3.py`) для расширения структуры данных (добавление новых типов тканей, категорий и связей).

### 2. Разработка парсеров и наполнение базы
- Созданы парсеры для сайтов:
  - **Davis Fabrics** (`scraper_davis.py`): сбор изображений, износостойкости и свойств.
  - **Litena** (`scraper_litena.py`): извлечение характеристик и оптимизация картинок.
  - **Toptextil** (`scraper_toptextil.py`): сбор данных о коллекциях с использованием автоматического рендеринга страниц через Playwright.
- Разработан импорт прайс-листов из Excel/PDF (`1_pdf_to_excel.py`, `import_excel.py`).
- Всего в базу данных успешно импортировано **1403 ткани** со всеми характеристиками.

### 3. Разработка API и интеграция интерфейса
- Реализованы эндпоинты в `backend/main.py`:
  - `GET /api/fabrics` — получение списка тканей с фильтрацией.
  - `GET /api/filters` — получение динамического списка доступных брендов и категорий для фильтров.
  - `PUT /api/fabrics/{id}/price` — быстрое обновление цены.
- Настроен фронтенд (`frontend/app.js`, `frontend/index.html`):
  - Сделан современный дизайн карточек тканей.
  - Реализован быстрый поиск с дебаунсом (задержка отправки запросов при вводе для снижения нагрузки на сервер).
  - Внедрена возможность редактирования цены прямо на карточке с визуальным подтверждением сохранения (зеленая рамка).

### 4. Автоматизация и синхронизация
- Создан скрипт `sync_to_github.py` для зеркального копирования изменений исходного кода и актуальной базы данных в репозиторий GitHub (`tkani-catalog`) с автоматическим коммитом и отправкой (`git push`).
- Создан скрипт `prepare_github.py` для автоматической сборки чистого релиза приложения перед отправкой.

### 5. Серверная настройка и безопасность (HTTPS)
- **Запуск службы бэкенда:** на сервере `95.111.234.116` настроена системная служба `fabrics.service` через `systemd`, которая обеспечивает автоматический запуск Uvicorn-сервера на порту `8080` и его перезапуск в случае сбоев.
- **Проксирование веб-сервера:** настроен веб-сервер Nginx для обработки внешних запросов к домену `fabrics.eleganthouse.pro` и перенаправления их на локальный бэкенд.
- **SSL-сертификат (HTTPS):** с помощью утилиты `certbot` и центра сертификации Let's Encrypt выпущен и установлен валидный SSL-сертификат безопасности.
- **Редирект на HTTPS:** настроено автоматическое перенаправление всех пользователей с HTTP (порт 80) на безопасный HTTPS (порт 443).
